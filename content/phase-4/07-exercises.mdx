# 4단계 종합 실습

이 실습은 4단계에서 배운 RDF 트리플, RDFS, OWL, SPARQL, 직렬화 형식을 통합적으로 연습합니다. 기본 실습부터 순서대로 진행하되, 도전 실습은 심화 학습자를 위한 것입니다.

## 기본 실습 1: 학교 도메인 트리플 작성

**목표**: "학교" 도메인에서 5개 이상의 트리플을 Turtle 형식으로 작성합니다.

**요구 사항:**
- 최소 2개의 클래스(예: 교수, 강의)
- 최소 1개의 클래스 계층(`rdfs:subClassOf`)
- 최소 1개의 데이터 프로퍼티 (리터럴 값)
- 최소 1개의 객체 프로퍼티 (자원 간 관계)
- 한국어와 영어 레이블 포함

**예시 개체:**
- 김철수 교수: 컴퓨터공학 전공, 2003년 임용
- CS101 강의: "프로그래밍 기초", 3학점
- 김철수 교수가 CS101 강의를 담당

**시작 템플릿:**

```turtle
@prefix ex: <http://school.example.org/> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .
@prefix foaf: <http://xmlns.com/foaf/0.1/> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

# 클래스 정의
ex:Professor a rdfs:Class ;
    rdfs:label "교수"@ko ;
    rdfs:label "Professor"@en .

# 여기에 계속 작성하세요
```

**체크리스트:**
- [ ] 네임스페이스 프리픽스 선언
- [ ] 클래스 선언 (`rdfs:Class`)
- [ ] 클래스 계층 (`rdfs:subClassOf`)
- [ ] 객체 프로퍼티와 도메인/범위
- [ ] 인스턴스와 다국어 레이블
- [ ] 날짜/숫자 리터럴 타입 지정

## 도전 실습 1: RDF/XML을 Turtle로 변환

**목표**: 다음 RDF/XML을 동일한 의미의 Turtle로 변환합니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<rdf:RDF
    xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#"
    xmlns:rdfs="http://www.w3.org/2000/01/rdf-schema#"
    xmlns:foaf="http://xmlns.com/foaf/0.1/"
    xmlns:ex="http://example.org/"
    xmlns:xsd="http://www.w3.org/2001/XMLSchema#">

    <rdfs:Class rdf:about="http://example.org/Library">
        <rdfs:label xml:lang="ko">도서관</rdfs:label>
        <rdfs:label xml:lang="en">Library</rdfs:label>
        <rdfs:comment xml:lang="ko">책과 자료를 소장하는 기관</rdfs:comment>
    </rdfs:Class>

    <rdfs:Class rdf:about="http://example.org/Book">
        <rdfs:label xml:lang="ko">책</rdfs:label>
        <rdfs:subClassOf rdf:resource="http://example.org/Resource"/>
    </rdfs:Class>

    <foaf:Person rdf:about="http://example.org/hong">
        <foaf:name xml:lang="ko">홍길동</foaf:name>
        <foaf:age rdf:datatype="http://www.w3.org/2001/XMLSchema#integer">30</foaf:age>
        <ex:memberOf rdf:resource="http://example.org/snu-library"/>
    </foaf:Person>

    <ex:Library rdf:about="http://example.org/snu-library">
        <rdfs:label xml:lang="ko">서울대학교 중앙도서관</rdfs:label>
        <ex:bookCount rdf:datatype="http://www.w3.org/2001/XMLSchema#integer">2000000</ex:bookCount>
    </ex:Library>
</rdf:RDF>
```

**변환 후 Turtle에 포함되어야 할 요소:**
- 모든 `@prefix` 선언
- 클래스 선언과 계층
- 인스턴스와 프로퍼티
- 다국어 레이블
- 타입 리터럴

**힌트**: RDFLib Python을 사용하면 자동 변환이 가능합니다:
```python
from rdflib import Graph
g = Graph()
g.parse(data="""(위의 XML)""", format="xml")
print(g.serialize(format="turtle"))
```

## 도전 실습 2: JSON-LD로 개인 프로필 온톨로지 표현

**목표**: 다음 개인 프로필 정보를 JSON-LD 형식으로 표현합니다. Schema.org와 FOAF 어휘를 적절히 사용합니다.

**표현할 정보:**
- 이름: 박지원 (영어: Ji-won Park)
- 직업: 소프트웨어 엔지니어
- 소속 회사: ABC 테크 주식회사 (서울 소재)
- 웹사이트: https://parkjiwon.example.com
- 이메일: jiwon@example.com
- 기술 분야: Python, Java, 온톨로지 공학
- 출판물: "한국어 온톨로지 구축 방법론" (2023년, DOI 포함)

**시작 템플릿:**

```json
{
  "@context": {
    "@vocab": "https://schema.org/",
    "foaf": "http://xmlns.com/foaf/0.1/",
    "ex": "http://example.org/"
  },
  "@id": "https://parkjiwon.example.com/profile",
  "@type": "Person",
  "name": "박지원"
}
```

**체크리스트:**
- [ ] `@context`에 필요한 어휘 선언
- [ ] `@id`로 URI 부여
- [ ] `@type`으로 클래스 명시
- [ ] 다국어 값 표현 (`@language` 사용)
- [ ] 중첩 객체 (소속 회사) 표현
- [ ] 배열 값 (기술 목록) 표현
- [ ] 외부 URI 참조 (`@type: "@id"`)

**참고 Schema.org 어휘:**
- `schema:Person`, `schema:name`, `schema:jobTitle`
- `schema:worksFor`, `schema:Organization`
- `schema:url`, `schema:email`
- `schema:knowsAbout`
- `schema:author`, `schema:ScholarlyArticle`

## 도전 실습 3: SPARQL CONSTRUCT로 형식 변환

**목표**: DBpedia에서 SPARQL CONSTRUCT 쿼리를 사용하여 특정 데이터를 다른 어휘로 변환합니다.

DBpedia는 `dbo:`, `foaf:` 등의 어휘를 사용합니다. 이를 `schema.org` 어휘로 변환하는 CONSTRUCT 쿼리를 작성하세요.

**변환 대상**: 한국의 도시 (상위 5개)

**변환 규칙:**
- `dbo:City` → `schema:City`
- `rdfs:label` (한국어) → `schema:name`
- `dbo:populationTotal` → `schema:population`
- `dbo:areaTotal` → `schema:containedInPlace` (아니면 적절한 대안)

```sparql
PREFIX dbo: <http://dbpedia.org/ontology/>
PREFIX dbr: <http://dbpedia.org/resource/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX schema: <https://schema.org/>

CONSTRUCT {
    ?city a schema:City ;
          schema:name ?name ;
          schema:population ?pop .
}
WHERE {
    ?city a dbo:City ;
          dbo:country dbr:South_Korea ;
          rdfs:label ?name ;
          dbo:populationTotal ?pop .
    FILTER (LANG(?name) = "ko")
}
ORDER BY DESC(?pop)
LIMIT 5
```

이 쿼리를 DBpedia SPARQL 엔드포인트에서 실행하고 결과를 Turtle로 저장해보세요.
