# 온톨로지 기초 학습 플랫폼에 오신 것을 환영합니다

이 플랫폼은 온톨로지(Ontology)의 핵심 개념을 한국어로 학습할 수 있도록 설계된 교육 사이트입니다.

## 학습 단계

이 강의는 9개의 단계로 구성되어 있습니다:

- [1단계: 왜 온톨로지가 필요한가?](/phase-1) — 온톨로지의 필요성과 기본 개념
- [2단계: 구성 요소](/phase-2) — 클래스, 속성, 공리의 기초
- [3단계: 논리적 기초](/phase-3) — 기술 논리와 추론의 원리
- [4단계: 표준과 언어 생태계](/phase-4) — RDF, OWL, SPARQL
- [5단계: 설계 방법론](/phase-5) — 온톨로지 설계 실무
- [6단계: 주요 표준 온톨로지](/phase-6) — FOAF, Schema.org, GO, SNOMED CT
- [7단계: 실전 적용](/phase-7) — 지식 그래프, LLM + RAG
- [8단계: 한계와 대안](/phase-8) — 비용, 대안 기술, 의사결정
- [9단계: 엔터프라이즈 온톨로지](/phase-9) — Palantir 사례 연구
