# 7회차: 종합 실습 — 코스 마무리

> "배움은 이해에서 시작하고 실천에서 완성된다."

이 마지막 실습은 8단계의 내용뿐만 아니라 이 코스 전체에서 배운 모든 것을 통합합니다. 각 실습은 실제 현업 상황을 반영하도록 설계되었습니다.

## 기본 실습 1: 기술 선택 시나리오 분석

### 과제 설명

다음 3가지 시나리오에서 각각 가장 적합한 기술을 선택하고 그 이유를 설명하세요. 5회차의 의사결정 트리를 반드시 활용하세요.

**시나리오 A: 국가 의약품 데이터베이스 시스템**

배경: 한국 식품의약품안전처가 모든 의약품의 성분, 효능, 부작용, 약물 상호작용을 통합 관리하는 시스템을 구축하려 합니다. 이 시스템은 병원, 약국, 의학 연구 기관 모두에서 사용하며, 정기적으로 해외 의약 데이터베이스(FDA, EMA)와 데이터를 교환해야 합니다. 약물 상호작용 추론("이 두 약을 함께 복용하면 위험한가?")이 핵심 기능입니다.

**시나리오 B: 배달 서비스 플랫폼**

배경: 신생 배달 앱 스타트업이 6개월 안에 서울 서비스를 시작해야 합니다. 핵심 기능은 음식점 목록, 메뉴 관리, 주문 처리, 배달 추적입니다. 투자자 데모가 2개월 후에 있고, 초기에는 10~20개 음식점만 등록됩니다.

**시나리오 C: 도서관 자료 통합 검색**

배경: 전국 200개 도서관이 보유한 자료를 하나의 검색 시스템으로 통합합니다. 각 도서관은 이미 자체 분류 체계를 가지고 있습니다. 주요 기능은 자료 검색, 관련 자료 추천, 주제별 분류 탐색입니다. 복잡한 논리적 추론은 필요하지 않습니다.

### 기대 답안 구조

각 시나리오에 대해 다음을 작성하세요:
1. **기술 선택**: 어떤 기술을 선택했는가? (온톨로지 OWL, 속성 그래프, RDBMS, SKOS)
2. **의사결정 경로**: 5회차 의사결정 트리의 어떤 경로를 따랐는가?
3. **선택 이유**: 이 기술이 왜 이 시나리오에 적합한가? (3가지 이상)
4. **대안 검토**: 다른 기술을 선택하지 않은 이유는? (1가지 대안과 배제 이유)
5. **위험 요소**: 이 선택의 잠재적 문제점과 완화 방법

### 평가 기준

| 항목 | 기준 |
|------|------|
| 기술 선택 적합성 | 선택한 기술이 요구사항에 맞는가? |
| 의사결정 논리 | 트리를 올바르게 따랐는가? |
| 대안 분석 깊이 | 대안을 진지하게 검토했는가? |
| 현실적 위험 인식 | 잠재적 문제를 파악했는가? |

## 기본 실습 2: 온톨로지 실패 사례 분석

### 과제 설명

다음 실패 사례를 읽고 분석 보고서를 작성하세요.

**사례: A 대형병원의 임상 의사결정 지원 시스템**

A 대형병원은 2015년 임상 의사결정 지원 시스템(Clinical Decision Support System, CDSS) 구축을 시작했습니다. 목표는 의사가 진단할 때 유사 환자 사례와 최신 의학 지식을 자동으로 제공하는 것이었습니다.

병원은 SNOMED CT 기반으로 온톨로지를 구축하기로 결정했습니다. 외부 컨설팅 회사를 고용해 3년간 온톨로지를 개발했습니다.

**문제 발생:**
- 컨설팅 회사가 계약 종료 후 내부에 온톨로지 전문가가 없음
- SNOMED CT가 2019년 대대적으로 업데이트되었지만 병원 온톨로지는 업데이트 불가
- 의사들이 시스템을 신뢰하지 않아 실제 사용률 5% 미만
- 2021년 시스템 사용 중단

**분석할 항목:**

1. **실패 원인 분류**: 기술적 실패인가? 조직적 실패인가? 계획 실패인가?
2. **8단계 관점 적용**: 1회차(비용)와 3회차(부적합 상황) 관점에서 무엇을 놓쳤는가?
3. **핵심 실수 3가지**: 이 프로젝트에서 가장 결정적인 실수 3가지를 꼽고 설명하세요
4. **사전 방지 방법**: 이 실패를 막으려면 처음에 어떤 결정을 다르게 해야 했는가?
5. **성공적 대안**: 같은 목표(임상 의사결정 지원)를 더 현실적으로 달성하는 방법은?

## 도전 실습 1: 자신의 도메인 온톨로지 적용 가능성 평가 보고서

### 과제 설명

자신이 현재 일하거나 공부하는 분야(직장, 학교, 연구 분야)를 선택하고, 그 도메인에서 온톨로지를 적용할 가능성을 평가하는 **2,000자 이상의 분석 보고서**를 작성하세요.

### 보고서 구조

**1. 도메인 소개 (300자 이상)**
- 선택한 도메인이 무엇인가?
- 현재 어떤 데이터와 지식이 사용되는가?
- 주요 이해관계자는 누구인가?

**2. 현재 상황 분석 (400자 이상)**
- 현재 어떤 시스템/도구로 지식을 관리하는가?
- 어떤 문제나 비효율이 존재하는가?
- 데이터 통합 문제가 있는가?

**3. 온톨로지 적용 가능성 평가 (500자 이상)**

다음 기준으로 평가하고 각 항목에 1~5점을 주세요:
- 도메인 복잡도 (개념과 관계의 복잡성)
- 추론 필요성 (명시적 논리 추론의 필요 여부)
- 상호운용성 요구 (외부 시스템과의 데이터 공유)
- 도메인 안정성 (지식이 얼마나 안정적인가)
- 팀 역량 (온톨로지 전문가 확보 가능성)
- 예산 가용성 (투자 여력)

총점과 그 의미를 해석하고 최종 권장 사항을 제시하세요.

**4. 구체적 구현 제안 (400자 이상)**

온톨로지가 적합하다면:
- 어떤 핵심 개념과 관계를 포함할 것인가?
- 어떤 기존 온톨로지(Gene Ontology, SNOMED 등)를 활용할 것인가?
- 어떤 단계로 구축할 것인가?

온톨로지가 부적합하다면:
- 어떤 대안 기술을 사용할 것인가?
- 온톨로지의 일부 개념(분류 체계)을 SKOS로 제한적 사용할 수 있는가?

**5. 위험과 완화 방법 (400자 이상)**
- 예상되는 3가지 주요 위험은?
- 각 위험을 어떻게 완화할 것인가?

## 도전 실습 2: "온톨로지 vs 벡터 임베딩" 양측 입장 에세이

### 과제 설명

**한국어로 1,500자 이상**의 에세이를 두 부분으로 나눠 작성하세요. 동일한 주제("의료 진단 보조 AI 시스템에서 온톨로지 vs 벡터 임베딩")에 대해 양쪽 입장을 모두 옹호합니다.

이 실습의 목적은 하나의 정답을 찾는 것이 아닙니다. 각 기술의 강점과 약점을 완전히 이해하고, 다양한 관점에서 논증하는 능력을 키우는 것입니다.

### 파트 1: 온톨로지 옹호 (750자 이상)

의료 진단 보조 AI 시스템에서 **온톨로지가 벡터 임베딩보다 우월하다**는 입장을 논증하세요.

논증에 포함할 내용:
- 의료 분야의 특수성 (설명 가능성, 책임 추적)
- 의약학 지식의 명확성과 정밀성 요구
- 오류의 결과 (환자 안전)
- 기존 의료 온톨로지(SNOMED CT, ICD) 활용 장점

### 파트 2: 벡터 임베딩 옹호 (750자 이상)

의료 진단 보조 AI 시스템에서 **벡터 임베딩이 온톨로지보다 우월하다**는 입장을 논증하세요.

논증에 포함할 내용:
- 의학 지식의 방대함과 지속적 변화
- 온톨로지 구축/유지 비용의 현실
- 최신 의학 논문에서 자동 학습의 장점
- 의료 언어의 모호성과 통계적 처리의 강점

### 파트 3: 개인 결론 (선택, 200자)

두 입장을 모두 쓴 후, 여러분의 개인적 의견을 짧게 추가할 수 있습니다. 어느 쪽이 더 설득력 있다고 생각하는지, 또는 어떤 하이브리드 접근이 최선인지를 서술합니다.

### 평가 기준

| 항목 | 기준 |
|------|------|
| 논증의 깊이 | 표면적 비교를 넘어 핵심 이유를 제시했는가? |
| 기술적 정확성 | 각 기술의 특성을 올바르게 이해했는가? |
| 균형성 | 양쪽 입장을 동등하게 성실히 논증했는가? |
| 의료 도메인 이해 | 의료 분야의 특수성을 이해했는가? |
| 글쓰기 명확성 | 논점이 명확하고 논리적으로 전개되는가? |

## 코스 완료 체크리스트

이 강의를 마치며, 다음 항목을 점검하세요:

**온톨로지 기초:**
- [ ] RDF, OWL의 핵심 개념을 설명할 수 있다
- [ ] SPARQL로 기본 쿼리를 작성할 수 있다
- [ ] 온톨로지 설계 원칙을 알고 있다

**실용적 판단력:**
- [ ] 온톨로지가 적합한 상황과 아닌 상황을 구별할 수 있다
- [ ] 4가지 기술(온톨로지, 속성 그래프, RDBMS, SKOS)의 장단점을 비교할 수 있다
- [ ] 의사결정 트리를 사용해 기술을 선택할 수 있다

**비용-편익 사고:**
- [ ] 온톨로지 구축 및 유지 비용을 현실적으로 평가할 수 있다
- [ ] ROI 관점에서 기술 선택을 정당화할 수 있다

**현대적 연결:**
- [ ] 벡터 임베딩과 온톨로지의 관계를 이해한다
- [ ] 하이브리드 접근법(RDF2Vec, 온톨로지+LLM)을 알고 있다
