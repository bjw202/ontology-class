# SPEC-ENHANCE-P7 인수 기준

## 시나리오 1: 현대자동차 Before/After (REQ-001)

### AC-001: Before 시나리오 존재

**Given** `06-industry-applications.mdx`의 현대자동차 섹션이 보강된 상태일 때
**When** 학습자가 해당 섹션을 읽으면
**Then** 온톨로지 없는 상황에서의 수동 결함 추적 과정이 구체적 단계(최소 3단계)로 서술되어 있다
**And** 시스템 간 용어 불일치 예시가 최소 3개 제시되어 있다
**And** 추적에 소요되는 시간/비용이 명시되어 있다

### AC-002: After 시나리오 존재

**Given** `06-industry-applications.mdx`의 현대자동차 Before 시나리오 뒤에
**When** After 섹션을 확인하면
**Then** 간소화된 온톨로지 스키마가 Turtle 형식으로 제시되어 있다 (최소 5개 클래스)
**And** 결함 원인 추적을 위한 SPARQL 쿼리 예제가 최소 1개 포함되어 있다
**And** 추적 시간 단축 효과가 명시되어 있다
**And** Turtle 스키마에 "간소화된 예시" 주석이 포함되어 있다

### AC-003: 차이점 요약 존재

**Given** Before/After 시나리오가 모두 서술된 후
**When** "무엇이 바뀌었는가" 섹션을 확인하면
**Then** 핵심 차이점이 최소 3가지로 요약되어 있다

## 시나리오 2: 구글 KG 엔티티 해소 (REQ-002)

### AC-004: 메커니즘 단계별 설명 존재

**Given** `02-knowledge-graphs.mdx`의 지식 패널 섹션 뒤에 보강 내용이 삽입된 상태일 때
**When** 엔티티 해소 메커니즘 섹션을 읽으면
**Then** "Paris" 등 모호한 검색어에 대한 문제 진술이 있다
**And** 엔티티 해소 과정이 최소 3단계로 설명되어 있다
**And** 각 단계에서 온톨로지의 역할이 명시되어 있다
**And** Mermaid 다이어그램으로 해소 과정이 시각화되어 있다

### AC-005: 부정 시나리오 포함

**Given** 엔티티 해소 메커니즘의 각 단계 설명에서
**When** "이 단계가 없으면?" 부분을 확인하면
**Then** 최소 2개 단계에 대해 해당 단계가 없을 때의 실패 결과가 서술되어 있다

## 시나리오 3: 검색 실패 Before/After (REQ-003)

### AC-006: 의료 검색 Before 시나리오

**Given** `03-search-recommendation.mdx`의 키워드 검색 한계 섹션에 보강 내용이 삽입된 상태일 때
**When** Before 시나리오를 읽으면
**Then** "당뇨" 키워드 검색으로 놓치는 구체적 문서 유형이 최소 3개 열거되어 있다
**And** 놓친 문서가 임상 판단에 미치는 영향이 언급되어 있다

### AC-007: 의료 검색 After 시나리오

**Given** Before 시나리오 뒤에
**When** After 시나리오를 읽으면
**Then** MeSH 온톨로지의 "당뇨" 관련 계층 일부가 Turtle 또는 구조화된 텍스트로 제시되어 있다
**And** 쿼리 확장 과정이 단계별(최소 3단계)로 보여진다
**And** 확장 검색이 추가로 찾아내는 문서 유형이 명시되어 있다

## 공통 품질 기준

### AC-011: Additive 변경 원칙

**Given** 보강이 완료된 3개 파일에서

### AC-012: Nextra 빌드 성공

**Given** 모든 보강이 완료된 상태에서
**When** `npm run build`를 실행하면
**Then** 빌드가 에러 없이 성공한다

### AC-013: Mermaid 렌더링

**Given** 보강에서 추가된 Mermaid 다이어그램이 포함된 페이지에서
**When** 브라우저에서 해당 페이지를 로드하면
**Then** 모든 Mermaid 다이어그램이 에러 없이 렌더링된다
**And** 아포스트로피(`'`)가 Mermaid 블록에 포함되어 있지 않다

### AC-014: 한국어 문체 일관성

**Given** 보강된 모든 섹션에서
**When** 문체를 검토하면
**Then** 존댓말 + 친근한 멘토 톤이 유지되어 있다
**And** 기술 용어는 영어와 한국어가 병기되어 있다 (첫 등장 시)

### AC-015: 연결 포인트 정확성

**Given** 보강에서 추가된 "연결 포인트" callout에서
**When** 참조하는 Phase/회차 번호를 확인하면
**Then** 모든 참조가 실제 존재하는 Phase와 회차를 정확히 가리킨다
